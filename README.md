# 300英雄 好运星盘自动占卜

基于屏幕识别与模版匹配的《300英雄》好运星盘小游戏自动化工具。自动完成「开始占卜 → 翻牌 → 计算最优连线 → 确认」的完整流程。

> **免责声明**
> 本项目仅供学习与个人研究使用（计算机视觉、模板匹配、期望值决策）。使用自动化工具可能违反游戏用户协议，存在账号被处罚的风险，**一切后果由使用者自行承担**。请勿用于商业用途或大规模刷取。

## 功能

- **自动完成整轮占卜**：识别界面元素、自动点击，无需人工干预
- **期望值决策**：根据已翻开的牌计算八条线的期望收益，选期望最高的那条
- **自适应翻牌**：翻牌前模拟所有可能性，优先翻开能带来最高预期收益的格子
- **断点续跑**：自动读取剩余次数，每轮递减，用完后自动停止
- **紧急停止**：鼠标甩到屏幕左上角立即中止，也可点界面上的停止按钮
- **失败重试**：每一步都有校验与重试，点击未生效会自动补点
- **运行日志**：实时输出到界面，每一步识别结果和决策依据都可见

## 环境要求

- Windows 10 / 11
- Python 3.10 及以上（代码使用了 `X | None` 联合类型语法）
- 安装 Python 时须勾选 **tcl/tk and IDLE**（tkinter 属于可选组件，缺失会导致 GUI 无法启动）

依赖：

```bash
pip install -r requirements.txt
```

包含 `pyautogui`、`mss`、`Pillow`、`keyboard`、`numpy`、`opencv-python`。

## 快速开始

1. 启动游戏，进入好运星盘占卜界面（能看到九宫格和「开始占卜」按钮的页面）
2. 双击 `启动.bat`
   - 脚本会自动检查 Python 版本、tkinter 和依赖
   - 检测到非管理员权限时会请求提权（**必须提权**，原因见「常见问题」）
3. 在输入框填入游戏里显示的**剩余占卜次数**
4. 点「▶ 开始」，3 秒后自动运行
5. 需要停止时点「■ 停止」，或把鼠标移到屏幕左上角

也可以直接用打包好的 `dist/酸败好运星盘.exe`（自带提权清单），或用 `python gui.py` 启动。

## 工作原理

```
截屏(mss) → 模板匹配(OpenCV) → 坐标推算 → 策略计算 → 点击(SendInput)
```

1. **窗口定位**：按标题匹配游戏窗口（`300英雄` / `300Heroes`），多个候选取面积最大的，用 `GetWindowRect` 拿到窗口区域
2. **截屏**：`mss` 只截游戏窗口区域，避免全屏处理开销
3. **元素识别**：OpenCV `matchTemplate`（`TM_CCOEFF_NORMED`）匹配 `temp/` 下的模板图
   - 按钮：开始 / 确认 / 选择
   - 箭头：8 个方向（含选中态 `sl*.png`）
   - 数字：1–9
4. **坐标推算**：不硬编码格子位置。用行箭头的 y 坐标当行中心、列箭头的 x 坐标当列中心，反推出九宫格九个格子的点击坐标，因此对分辨率变化有一定适应性
5. **期望值决策**：`config.REWARD_TABLE` 是「三牌点数之和 → 星砂奖励」的映射，呈 U 型分布（两端高、中间低）。对每条线的未知格子穷举所有可能数字组合，取平均奖励作为该线的期望值
6. **自适应翻牌**：对每个未翻开的格子，假设它是任意一个未出现的数字，计算翻开后能达到的最优期望，取平均值。选平均值最高的格子翻
7. **点击**：`SetCursorPos` 定位 + `SendInput` 发送左键事件

```
├── 启动.bat            # 一键启动（环境自检 + 自动提权）

├── temp/               # 模板图片（数字 1-9、箭头 l0-l7 及选中态、按钮）
└── dist/               # 打包产物（不纳入版本控制）
```

## 配置

所有可调参数集中在 `config.py`：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `REWARD_TABLE` | 见上表 | 奖励映射，游戏版本更新后需核对 |
| `MATCH_THRESHOLD_DIGIT` | 0.75 | 数字识别阈值，识别不准时优先调这个 |
| `MATCH_THRESHOLD_BUTTON` | 0.80 | 按钮识别阈值 |
| `MATCH_THRESHOLD_ARROW` | 0.80 | 箭头识别阈值 |
| `DELAY_AFTER_START` | 2.5 | 点击开始后的等待（秒），机器慢可加大 |
| `DELAY_AFTER_FLIP` | 1.2 | 每次翻牌的动画等待 |
| `HOTKEY_START` / `HOTKEY_STOP` | F5 / F6 | `main.py` 版本的热键 |

## 调试

识别不准时（日志一直报「未找到按钮」或格子坐标不全），在占卜界面运行：

```bash
python debug_match.py
```

它会截取当前画面存为 `debug_screenshot.png`，并逐个输出 4 个按钮、8 个箭头、9 个格子的匹配结果，直观看出哪张模板对不上。

常见处理方式：

- **箭头/按钮匹配不到** → 分辨率与原模板差异过大，需要按自己的分辨率重新截模板，替换 `temp/` 下对应文件
- **数字识别不到** → 先调低 `MATCH_THRESHOLD_DIGIT`（如 0.70）试试；仍不行则重截数字模板
- **格子坐标偏移** → 通常是游戏窗口有额外边框，检查 `compute_grid_from_arrows` 里的 `INWARD_OFFSET`

运行测试：

```bash
python test_strategy.py
```

双击 `build.bat`，或手动执行：

```bash
python -m PyInstaller --onefile --windowed --name "酸败好运星盘" ^
```

## 常见问题

**Q：程序启动了，但游戏完全没反应？**

几乎都是权限问题。如果游戏以管理员身份运行，而本程序是普通权限，Windows 的 **UIPI（用户界面特权隔离）** 会静默丢弃鼠标消息——光标能动，但点击送不进去。解决：右键 `启动.bat` 选「以管理员身份运行」，或直接用 `dist` 里的 exe（自带提权）。程序启动时会自动检测这种权限不对等并报错。

**Q：双击 bat 一闪而过？**

`bat` 文件必须是 **GBK 编码 + CRLF 换行**。UTF-8 编码的中文 bat 会被 cmd 按 GBK 解析，多行 `if (...)` 块直接崩。另外确认 PATH 里的 `python` 是带 tkinter 的那个，避免被其它精简版 Python 抢跑。

**Q：报 `No module named 'tkinter'`？**

当前 Python 安装时没勾 `tcl/tk`。重新运行 Python 安装程序，选 Modify，勾上 **tcl/tk and IDLE**。

**Q：识别到的格子位置/数字是错的？**

用 `debug_match.py` 看实际匹配情况。模板图与游戏分辨率强绑定，换分辨率或游戏 UI 更新后需要重截模板。

**Q：占卜中途想停下来？**

点「■ 停止」，或者把鼠标移到屏幕左上角（急停，3 秒倒计时阶段也生效）。急停触发后要先把鼠标移开左上角，再点开始才能恢复。
